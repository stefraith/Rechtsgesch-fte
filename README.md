# Erklärvideo: Rechtsgeschäfte

Webseite mit dem Erklärvideo (ca. 2,5 Minuten) und dem Transkript darunter. Keine Anmeldung nötig, läuft auf Handy, Tablet und Laptop.

## Dateien

- `index.html`: die Webseite
- `video.mp4`: das Video (ca. 6 MB)
- `poster.jpg`: Vorschaubild, bevor das Video startet

Alle drei Dateien müssen **direkt nebeneinander** im Repository liegen, nicht in einem Unterordner.

## Veröffentlichen mit GitHub Pages

1. Auf github.com: **+ → New repository**, Name z. B. `rechtsgeschaefte`, **Public**, **Create repository**.
2. **uploading an existing file** anklicken, `index.html`, `video.mp4` und `poster.jpg` gleichzeitig hineinziehen, **Commit changes**.
3. **Settings → Pages**: „Deploy from a branch“, Branch **main**, Ordner **/ (root)**, **Save**.
4. Nach 1 bis 2 Minuten erscheint die Adresse, z. B. `https://IHR-NAME.github.io/rechtsgeschaefte/`.
